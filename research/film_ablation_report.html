FiLM ablation on SmolVLA: z dimension, layer position and layer count (LIBERO-Object, LIBERO-10)

Follow-up to coupled vs split FiLM. Which FiLM placement and how many z dimensions give the most usable control space, measured by closed-loop axis grids and held-out re-runs of the best grid z. No CEM in this round.

Setup

  • Injection (all variants): split FiLM with γ on normalized x, on the action-expert MLP outputs x of the chosen layers: x' = x + γ ⊙ x̂ + β, x̂ = per-sample, per-channel InstanceNorm over the 50 action tokens; γ = α·Wγ·z[0:d/2], β = α·Wβ·z[d/2:d], each block Gaussian / √(d/2). Same γ, β for all tokens and all 10 denoising steps.
  • W bank: every layer has fixed γ and β columns (8 each, seed 0), whatever the layer set or d; d = 2k uses the first k of each. A layer shared by two variants has the same W in both, and the W of the reference R′ (layers 7, 15, 23, 31, d = 8) is bit-identical to film_split's, so its grids and picks are reused.
  • Axis names: γ axes 0–7, β axes 8–15 (d16 order). R′ and every layer variant have γ 0–3 and β 8–11.
  • Strength: parameter-space parity. Along an axis z = c·√d·e_k, every γ or β entry has sd α·c·√2 for any d. Across layer counts the total energy is held: α = 0.3·√(4/L) (1 layer 0.6, 2 layers 0.42, 4 layers 0.3, 16 layers 0.15). The open-loop gain is measured for each variant but not used to tune α; the last figure re-plots success against it.
  • Layer variants (cross-attention layers only, i.e. odd layers; even layers are joint self-attention):

  • z dimension: on R′ layers, one d = 16 grid (R′'s 8 axes + 8 new). With the nested W, axis k is the same vector in γ/β space for every d, so d = 2k is the first k γ and first k β axes of that grid.
  • Tasks: LIBERO-Object t0, t7 (as film_split), and four LIBERO-10 tasks picked by a z = 0 pilot for room in both directions (held-out z = 0 in brackets, max 520 steps): t1 put both the cream cheese box and the butter in the basket (0.30), t2 turn on the stove and put the moka pot on it (0.55), t6 put the white mug on the plate and the chocolate pudding to the right of the plate (0.30), t9 put the yellow and white mug in the microwave and close it (0.55).
  • Closed-loop grid (research/run.py): every axis at c ∈ {±0.5, ±1, ±2}, inits 0–7, one episode each, flow noise paired by init (z = 0 episodes are bitwise identical across grids, except LIBERO-10 t2 and t9, see takeaways). Held-out: the best γ cell and the best β cell of each variant (and of each d subset) on inits 10–39 × 2 reps (n = 60), paired with the ticket round's z = 0.
  • 2-D grid: in the plane of the best γ and best β axis of the d = 16 grid, a, b ∈ {±0.5, ±1}.
  • LIBERO-10 differences: the d = 16 grid is two 8-axis runs on R′ (γ axes 0–7, β axes 8–15, same c scale), and the held-out z = 0 is its own run (inits 10–39 × 2) instead of the ticket round's.
  • Machines: object on the local RTX 4090 laptop, B = 12 envs, as film_split (experiments/libero/film_ablation/local.sh); LIBERO-10 on Sol A100s, B = 30 (experiments/libero/film_ablation/sol.sh, open loop locally). Figures research/plot_film_ablation.py.

Takeaways

  • The split is object vs LIBERO-10, not between variants. On object t0 / t7 the best grid pick of almost every variant beats z = 0 on held-out: 19 / 26 and 21 / 26 picks are significantly better and none worse (best 0.95 f4 β and 0.97 l1 β, vs z = 0 0.42 / 0.43). On LIBERO-10 the same procedure rarely transfers: 4, 3, 7 and 0 of 26 picks are significantly better on t1, t2, t6, t9, and on t9 17 / 26 are significantly worse than z = 0 (0.55). Best LIBERO-10 held-outs: t1 0.50 (z = 0 0.30, l4 γ), t2 0.72–0.73 (0.55; s16 β, d16 β, 2-D combo), t6 0.53 (0.30, l1 γ), t9 none.
  • Not a larger push per step. Open-loop action change at c = 1 is on the same scale on LIBERO-10 (0.11–0.35) as on object (0.12–0.36), and below the flow-noise sd (0.34–0.46). Yet on t1 / t6 the grid mean at c = ±0.5 is below z = 0 for every variant (0.15–0.39 vs 0.62): the same action change costs more success there (last figure). |c| < 0.5 was not tested; one untested reading is that a fixed z over up to 520 steps lets small deviations add up.
  • Variants differ mostly in step size. Within a task, grid success (mean over axes and signs) against the measured open-loop action change at the same |c| falls on about one curve for all 13 variants. Parameter-energy parity is not action parity: front layers move the action most, so they sit further down that curve at a given c.
  • 8-init grid picks are optimistic. The 2-D combo grids peak at 0.875 / 1.0 on object, but their picks reach only 0.50 / 0.53 on held-out (n.s.), below the single-axis picks: 16 more candidates, more selection noise. On t9 the grid inits 0–7 are hard (z = 0 0.12–0.25 vs 0.55 on held-out inits), so picks chosen there may not suit the held-out inits.
  • z dimension (object): the β pick's held-out rises from d = 2 (0.50 / 0.60) to d = 4 (0.88 / 0.87), then stays; γ needs d = 8 (0.80 / 0.67). The 8 extra axes of d = 16 never won a pick on object; on LIBERO-10 they won 6 of 8 picks but held-out did not improve (only t2 β 0.73, p = 0.02). The effective rank of ∂a/∂z keeps growing with d (mean 1.6, 2.4, 3.3, 4.1 for d = 2, 4, 8, 16), so success saturates before the rank does.
  • Position and count. At equal parameter energy, front layers move the action most (gain 0.21–0.36 at c = 1) and late layers least (0.11–0.21). On object, front β picks are good on both tasks (0.77–0.95), 16-layer β is the weakest (0.48 / 0.58) and 1-layer mid β is weak (0.52 / 0.55); γ picks show no position pattern, and 1 vs 2 vs 4 layers has no consistent effect. On LIBERO-10 no position or count is consistently better.
  • Pairing caveat. z = 0 episodes are not reproducible on LIBERO-10 t2 (they differ even between two identical local runs) and t9 (they differ between Sol runs; two local runs matched). Object and LIBERO-10 t1 / t6 are bitwise identical. On t2 / t9 the W/L sign tests stay valid but lose the power of paired noise.
