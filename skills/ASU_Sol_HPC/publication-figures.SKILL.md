## What I do

- Turn results into figures that meet journal requirements
- Review an existing figure against the claim it is used to support
- Fix palettes, scales, and labelling that mislead

## When to use me

Use me when preparing a figure for a paper, poster, or thesis, or when reviewing
someone else's.

## Safety

Figures are written as new files from a script; I do not edit source data, drop
"inconvenient" points, or overwrite a figure that is already cited somewhere.
If a figure needs to change, the script changes and it is regenerated.

## Non-negotiables

1. **Axes are labelled with units.** No exceptions, including colorbars.
2. **Uncertainty is shown** — error bars, CIs, or the distribution — and the
   caption says what it is (SD, SEM, 95% CI, n).
3. **A truncated axis is disclosed.** Never start a bar chart's axis above zero.
4. **The palette is colorblind-safe** (viridis/cividis for continuous, Okabe–Ito
   for categorical). Never use rainbow/jet for continuous data.
5. **Color is not the only channel.** Vary line style and marker too — the figure
   must survive greyscale printing.
6. **The caption states the claim** and matches what is plotted.

## Practical defaults

```python
import matplotlib as mpl
import matplotlib.pyplot as plt

mpl.rcParams.update({
    "figure.dpi": 150,          # on-screen
    "savefig.dpi": 600,         # raster fallback
    "font.size": 9,             # ~9pt is legible at single-column width
    "axes.labelsize": 9,
    "axes.spines.top": False,
    "axes.spines.right": False,
    "legend.frameon": False,
    "savefig.bbox": "tight",
    "pdf.fonttype": 42,         # editable/embeddable text, not outlines
    "ps.fonttype": 42,
})

OKABE_ITO = ["#0072B2", "#E69F00", "#009E73", "#CC79A7",
             "#56B4E9", "#D55E00", "#F0E442", "#000000"]

fig, ax = plt.subplots(figsize=(3.4, 2.6))   # single column ≈ 3.4 in
ax.errorbar(x, mean, yerr=ci95, marker="o", color=OKABE_ITO[0], capsize=3,
            label="Method A")
ax.set_xlabel("Number of ranks")
ax.set_ylabel("Time to solution (s)")
ax.legend()
fig.savefig("results/fig3_scaling.pdf")      # vector, not PNG
```

Size the figure at its final printed size and never scale it in the document —
that is what makes text illegible.

## Choosing the chart

| Question | Use | Avoid |
| --- | --- | --- |
| Trend over a continuum | Line | Bars |
| Comparison of a few groups | Dot plot with CI | 3D bars |
| Distribution | Box + jittered points, or violin | Bar of means alone |
| Two variables | Scatter, with a fit only if justified | Connecting unordered points |
| Field / matrix | Heatmap with a perceptually uniform colormap | Jet |
| Scaling study | Log–log with an ideal-scaling reference line | Linear axes hiding the knee |

Plot the data, not just a summary: bar-of-means hides bimodality, outliers, and
tiny sample sizes. With n < 20, show every point.

## Review checklist

- [ ] Legible at final printed size (print it, do not zoom)
- [ ] Axes labelled with units; log axes marked as log
- [ ] Uncertainty shown and defined; n stated
- [ ] Colorblind-safe and greyscale-safe
- [ ] Vector format (PDF/SVG/EPS), fonts embedded as type 42
- [ ] No chartjunk: no 3D, no gradients, no duplicate legends
- [ ] Every element in the figure is referenced in the caption or text
- [ ] The figure is regenerated by a script in the repo, not edited by hand
